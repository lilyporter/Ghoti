This project is a software tool that analyzes recorded and real-time speech at the phonetic level (using the International Phonetic Alphabet) and flags speech patterns and challenges that may be relevant to a speech therapist.

The folders and files for this project are as follows:

docs - Documentation for the project
refs - Reference material used for the project, including papers
src - Source code
test - Test cases
etc.

The documentation for this project is updated on the project's [GitHub page](https://lilyporter.github.io/Ghoti/).
